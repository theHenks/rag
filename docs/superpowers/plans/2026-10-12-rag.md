# rag Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A local hybrid-search index over PDFs (Indico talks, papers, theses, notes), queried by Claude Code through MCP and by a `rag` CLI.

**Architecture:** MinerU 4 parses each PDF once into typed blocks (cached per checksum). Blocks become chunks, which are embedded densely (Qwen3-Embedding-0.6B on MPS) and sparsely (BM25 via fastembed) and stored in a Qdrant server in Docker. A SQLite catalog is the source of truth for documents and ingest jobs; a single detached worker process runs jobs. An MCP server (mcp 2.x `MCPServer`, stdio) and an argparse CLI sit on top of the same functions.

**Tech Stack:** Python 3.12, uv, mineru 4.0.12, qdrant-client 1.19, fastembed 0.9, sentence-transformers 6.1, mcp 2.3, httpx, platformdirs, SQLite, pytest + pytest-asyncio, Docker (Qdrant), Ollama (gemma4 vision).

**Spec:** `docs/superpowers/specs/2026-10-12-rag-design.md`

@dataclass
class Manifest:
    path: Path
    records: dict[str, TalkRecord] = field(default_factory=dict)
    event: EventInfo | None = None

    @classmethod
    def load(cls, path: Path) -> "Manifest":
        if not path.exists():
            return cls(path=path)
        payload = json.loads(path.read_text(encoding="utf-8"))
        records = {key: TalkRecord(**value) for key, value in payload.get("talks", {}).items()}
        raw_event = payload.get("event")
        event = None
        if raw_event is not None:
            event = EventInfo(host=raw_event["host"], id=raw_event["id"], title=raw_event["title"])
        return cls(path=path, records=records, event=event)

```python
"""Settings, read from a TOML file whose keys are the fields of `Config`."""
from __future__ import annotations

import os
import tomllib
from dataclasses import dataclass, field, fields
from pathlib import Path

import platformdirs


def _default_data_dir() -> Path:
    return Path(platformdirs.user_data_dir("rag"))


@dataclass(frozen=True)
class Config:
    data_dir: Path = field(default_factory=_default_data_dir)
    qdrant_url: str = "http://localhost:6333"
    collection: str = "rag"
    dense_model: str = "Qwen/Qwen3-Embedding-0.6B"
    sparse_model: str = "Qdrant/bm25"
    device: str = "mps"
    chunk_tokens: int = 450
    mineru_tier: str = "standard"
    ollama_url: str = "http://localhost:11434"
    vision_model: str = "gemma4:31b-mlx"

    @property
    def catalog_path(self) -> Path:
        return self.data_dir / "catalog.sqlite3"

    @property
    def cache_dir(self) -> Path:
        """MinerU output, one directory per document checksum."""
        return self.data_dir / "mineru"

    @property
    def models_dir(self) -> Path:
        """fastembed's model cache; its default lives under $TMPDIR, which macOS clears."""
        return self.data_dir / "models"

    @property
    def log_path(self) -> Path:
        return self.data_dir / "worker.log"


def config_path() -> Path:
    """`$RAG_CONFIG` if set, else `config.toml` in the platform config directory."""
    override = os.environ.get("RAG_CONFIG")
    if override:
        return Path(override).expanduser()
    return Path(platformdirs.user_config_dir("rag")) / "config.toml"


def load_config(path: Path | None = None) -> Config:
    path = path or config_path()
    if not path.exists():
        return Config()
    raw = tomllib.loads(path.read_text(encoding="utf-8"))
    known = {f.name for f in fields(Config)}
    unknown = sorted(set(raw) - known)
    if unknown:
        raise ValueError(
            f"unknown keys in {path}: {', '.join(unknown)} (known keys: {', '.join(sorted(known))})"
        )
    if "data_dir" in raw:
        raw["data_dir"] = Path(raw["data_dir"]).expanduser()
    return Config(**raw)
```

"""The authoritative record of documents and ingest jobs, in SQLite.

Every process (CLI, MCP server, worker) opens its own connection; WAL mode
lets readers proceed while the worker writes.
"""
from __future__ import annotations

import json
import os
import sqlite3
from dataclasses import dataclass, field
from datetime import datetime, timezone
from pathlib import Path

_SCHEMA = """
CREATE TABLE IF NOT EXISTS documents (
    id TEXT PRIMARY KEY, title TEXT NOT NULL, source_type TEXT NOT NULL,
    authors TEXT NOT NULL, date TEXT, tags TEXT NOT NULL,
    event_id TEXT, event_title TEXT, session TEXT, indico_url TEXT,
    enrich INTEGER NOT NULL, status TEXT NOT NULL, settings TEXT,
    page_count INTEGER, error TEXT, updated_at TEXT NOT NULL
);
CREATE TABLE IF NOT EXISTS paths (
    path TEXT PRIMARY KEY,
    document_id TEXT NOT NULL REFERENCES documents(id) ON DELETE CASCADE
);
CREATE TABLE IF NOT EXISTS jobs (
    id INTEGER PRIMARY KEY AUTOINCREMENT, kind TEXT NOT NULL, args TEXT NOT NULL,
    status TEXT NOT NULL, worker_pid INTEGER, error TEXT,
    interruptions INTEGER NOT NULL DEFAULT 0,
    created_at TEXT NOT NULL, started_at TEXT, finished_at TEXT
);
CREATE TABLE IF NOT EXISTS job_files (
    job_id INTEGER NOT NULL REFERENCES jobs(id) ON DELETE CASCADE,
    path TEXT NOT NULL, document_id TEXT, stage TEXT NOT NULL,
    status TEXT NOT NULL, error TEXT,
    PRIMARY KEY (job_id, path)
);
CREATE TABLE IF NOT EXISTS worker (
    slot INTEGER PRIMARY KEY CHECK (slot = 1), pid INTEGER NOT NULL, started_at TEXT NOT NULL
);
"""


def _now() -> str:
    return datetime.now(timezone.utc).isoformat(timespec="seconds")


def pid_alive(pid: int) -> bool:
    try:
        os.kill(pid, 0)
    except ProcessLookupError:
        return False
    except PermissionError:
        return True
    return True


@dataclass
class Document:
    id: str
    title: str
    source_type: str
    authors: list[str]
    date: str | None
    tags: list[str]
    event_id: str | None
    event_title: str | None
    session: str | None
    indico_url: str | None
    enrich: bool
    status: str
    settings: str | None
    page_count: int | None
    error: str | None
    paths: list[str] = field(default_factory=list)


@dataclass
class Job:
    id: int
    kind: str
    args: dict
    status: str
    worker_pid: int | None
    error: str | None
    interruptions: int
    created_at: str
    started_at: str | None
    finished_at: str | None


@dataclass
class JobFile:
    job_id: int
    path: str
    document_id: str | None
    stage: str
    status: str
    error: str | None


class Catalog:
    def __init__(self, path: Path):
        path.parent.mkdir(parents=True, exist_ok=True)
        self.db = sqlite3.connect(path, timeout=30, isolation_level=None)
        self.db.row_factory = sqlite3.Row
        self.db.execute("PRAGMA journal_mode=WAL")
        self.db.execute("PRAGMA foreign_keys=ON")
        self.db.executescript(_SCHEMA)

    # documents

    def put_document(self, doc: Document) -> None:
        """Insert or update a document. An upsert rather than INSERT OR REPLACE,
        which would delete the row and cascade to its paths."""
        self.db.execute(
            """INSERT INTO documents VALUES (?,?,?,?,?,?,?,?,?,?,?,?,?,?,?,?)
               ON CONFLICT(id) DO UPDATE SET title=excluded.title, source_type=excluded.source_type,
                 authors=excluded.authors, date=excluded.date, tags=excluded.tags,
                 event_id=excluded.event_id, event_title=excluded.event_title, session=excluded.session,
                 indico_url=excluded.indico_url, enrich=excluded.enrich, status=excluded.status,
                 settings=excluded.settings, page_count=excluded.page_count, error=excluded.error,
                 updated_at=excluded.updated_at""",
            (doc.id, doc.title, doc.source_type, json.dumps(doc.authors), doc.date,
             json.dumps(doc.tags), doc.event_id, doc.event_title, doc.session, doc.indico_url,
             int(doc.enrich), doc.status, doc.settings, doc.page_count, doc.error, _now()),
        )

    def _document(self, row: sqlite3.Row) -> Document:
        paths = [r["path"] for r in self.db.execute(
            "SELECT path FROM paths WHERE document_id = ? ORDER BY path", (row["id"],))]
        return Document(
            id=row["id"], title=row["title"], source_type=row["source_type"],
            authors=json.loads(row["authors"]), date=row["date"], tags=json.loads(row["tags"]),
            event_id=row["event_id"], event_title=row["event_title"], session=row["session"],
            indico_url=row["indico_url"], enrich=bool(row["enrich"]), status=row["status"],
            settings=row["settings"], page_count=row["page_count"], error=row["error"], paths=paths,
        )

    def get_document(self, id: str) -> Document | None:
        row = self.db.execute("SELECT * FROM documents WHERE id = ?", (id,)).fetchone()
        return self._document(row) if row else None

    def list_documents(self, *, source_type: str | None = None, tag: str | None = None,
                       event_id: str | None = None) -> list[Document]:
        query, args = "SELECT * FROM documents WHERE 1=1", []
        if source_type:
            query += " AND source_type = ?"
            args.append(source_type)
        if event_id:
            query += " AND event_id = ?"
            args.append(event_id)
        if tag:
            query += " AND EXISTS (SELECT 1 FROM json_each(documents.tags) WHERE value = ?)"
            args.append(tag)
        query += " ORDER BY date IS NULL, date, title"
        return [self._document(row) for row in self.db.execute(query, args)]

    def delete_document(self, id: str) -> None:
        self.db.execute("DELETE FROM documents WHERE id = ?", (id,))

    def set_status(self, id: str, status: str, *, settings: str | None = None,
                   error: str | None = None) -> None:
        self.db.execute(
            "UPDATE documents SET status = ?, settings = COALESCE(?, settings), error = ?, updated_at = ? WHERE id = ?",
            (status, settings, error, _now(), id),
        )

    def add_path(self, path: str, document_id: str) -> str | None:
        previous = self.documents_for_path(path)
        self.db.execute("INSERT OR REPLACE INTO paths VALUES (?, ?)", (path, document_id))
        return previous if previous != document_id else None

    def documents_for_path(self, path: str) -> str | None:
        row = self.db.execute("SELECT document_id FROM paths WHERE path = ?", (path,)).fetchone()
        return row["document_id"] if row else None

    # jobs

    def _job(self, row: sqlite3.Row) -> Job:
        return Job(id=row["id"], kind=row["kind"], args=json.loads(row["args"]), status=row["status"],
                   worker_pid=row["worker_pid"], error=row["error"], interruptions=row["interruptions"],
                   created_at=row["created_at"], started_at=row["started_at"], finished_at=row["finished_at"])

    def create_job(self, kind: str, args: dict) -> int:
        cur = self.db.execute(
            "INSERT INTO jobs (kind, args, status, created_at) VALUES (?, ?, 'queued', ?)",
            (kind, json.dumps(args), _now()),
        )
        return cur.lastrowid

    def get_job(self, id: int) -> Job | None:
        row = self.db.execute("SELECT * FROM jobs WHERE id = ?", (id,)).fetchone()
        return self._job(row) if row else None

    def recent_jobs(self, limit: int = 10) -> list[Job]:
        rows = self.db.execute("SELECT * FROM jobs ORDER BY id DESC LIMIT ?", (limit,))
        return [self._job(row) for row in rows]

    def next_queued_job(self) -> Job | None:
        row = self.db.execute("SELECT * FROM jobs WHERE status = 'queued' ORDER BY id LIMIT 1").fetchone()
        return self._job(row) if row else None

    def start_job(self, id: int, pid: int) -> None:
        self.db.execute(
            "UPDATE jobs SET status = 'running', worker_pid = ?, started_at = COALESCE(started_at, ?) WHERE id = ?",
            (pid, _now(), id),
        )

    def finish_job(self, id: int, status: str, error: str | None = None) -> None:
        self.db.execute("UPDATE jobs SET status = ?, error = ?, finished_at = ? WHERE id = ?",
                        (status, error, _now(), id))

    def requeue_dead_jobs(self) -> list[int]:
        """Put back running jobs whose worker process no longer exists."""
        dead = [row["id"] for row in self.db.execute("SELECT id, worker_pid FROM jobs WHERE status = 'running'")
                if row["worker_pid"] is None or not pid_alive(row["worker_pid"])]
        for id in dead:
            self.db.execute(
                "UPDATE jobs SET status = 'queued', worker_pid = NULL, interruptions = interruptions + 1 WHERE id = ?",
                (id,),
            )
        return dead

    def add_job_file(self, job_id: int, path: str) -> None:
        self.db.execute(
            "INSERT OR IGNORE INTO job_files (job_id, path, stage, status) VALUES (?, ?, 'queued', 'pending')",
            (job_id, path),
        )

    def update_job_file(self, job_id: int, path: str, *, stage: str, status: str,
                        document_id: str | None = None, error: str | None = None) -> None:
        self.db.execute(
            """UPDATE job_files SET stage = ?, status = ?, document_id = COALESCE(?, document_id), error = ?
               WHERE job_id = ? AND path = ?""",
            (stage, status, document_id, error, job_id, path),
        )

    def job_files(self, job_id: int) -> list[JobFile]:
        rows = self.db.execute("SELECT * FROM job_files WHERE job_id = ? ORDER BY path", (job_id,))
        return [JobFile(**dict(row)) for row in rows]

    # worker lock

    def acquire_worker(self, pid: int) -> bool:
        """Take the single worker slot; a slot held by a dead process is taken over."""
        self.db.execute("BEGIN IMMEDIATE")
        try:
            row = self.db.execute("SELECT pid FROM worker WHERE slot = 1").fetchone()
            if row and row["pid"] != pid and pid_alive(row["pid"]):
                self.db.execute("ROLLBACK")
                return False
            self.db.execute("INSERT OR REPLACE INTO worker VALUES (1, ?, ?)", (pid, _now()))
            self.db.execute("COMMIT")
            return True
        except BaseException:
            self.db.execute("ROLLBACK")
            raise

    def release_worker(self, pid: int) -> None:
        self.db.execute("DELETE FROM worker WHERE slot = 1 AND pid = ?", (pid,))

    def worker_pid(self) -> int | None:
        row = self.db.execute("SELECT pid FROM worker WHERE slot = 1").fetchone()
        if row is None or not pid_alive(row["pid"]):
            return None
        return row["pid"]

```python
"""MinerU parsing, its on-disk cache, and the block model built from it.

A parse directory holds MinerU's own output (`middle_json.json`, `images/`, …)
plus two files written here: `content_list.json` (MinerU's flat block list)
and `meta.json` (title, authors, creation date, page sizes). Everything after
parsing reads only those two files and the images.
"""
from __future__ import annotations

import json
import os
import re
import shutil
from dataclasses import dataclass, field
from html.parser import HTMLParser
from importlib.metadata import PackageNotFoundError, version
from pathlib import Path


class MinerUMissing(RuntimeError):
    pass


class UnknownBlockType(ValueError):
    pass


@dataclass(frozen=True)
class Block:
    kind: str
    text: str
    page: int
    bbox: tuple[int, int, int, int]
    level: int | None = None
    image: str | None = None
    caption: str = ""
    rows: tuple[str, ...] = ()


@dataclass(frozen=True)
class Parsed:
    directory: Path
    title: str | None
    authors: list[str]
    created_at: str | None
    pages: list[tuple[float, float]]
    blocks: list[Block] = field(default_factory=list)

    def image_path(self, block: Block) -> Path:
        if block.image is None:
            raise ValueError(f"block on page {block.page} has no image")
        return self.directory / block.image

    @property
    def landscape(self) -> bool:
        return bool(self.pages) and all(w > h for w, h in self.pages)


_DROPPED = {"header", "footer", "page_number", "aside_text", "index"}


def _clean(text: str) -> str:
    return re.sub(r"\s+", " ", text.replace("**", "")).strip()


class _TableRows(HTMLParser):
    def __init__(self):
        super().__init__()
        self.rows: list[list[str]] = []
        self._cell: list[str] | None = None

    def handle_starttag(self, tag, attrs):
        if tag == "tr":
            self.rows.append([])
        elif tag in ("td", "th"):
            self._cell = []

    def handle_endtag(self, tag):
        if tag in ("td", "th") and self._cell is not None:
            self.rows[-1].append(_clean("".join(self._cell)))
            self._cell = None

    def handle_data(self, data):
        if self._cell is not None:
            self._cell.append(data)


def table_rows(html: str) -> list[str]:
    parser = _TableRows()
    parser.feed(html)
    return [" | ".join(cells) for cells in parser.rows if any(cells)]


def blocks_from_content_list(items: list[dict]) -> list[Block]:
    """Turn MinerU's content list (v1) into blocks, dropping page furniture."""
    blocks: list[Block] = []
    for item in items:
        kind = item["type"]
        if kind in _DROPPED:
            continue
        page = item["page_idx"]
        bbox = tuple(item.get("bbox") or (0, 0, 0, 0))
        if kind in ("text", "page_footnote"):
            text = _clean(item.get("text", ""))
            if text:
                level = item.get("text_level")
                blocks.append(Block("title" if level else "text", text, page, bbox, level=level))
        elif kind in ("image", "chart"):
            caption = _clean(" ".join(item.get(f"{kind}_caption", []) + item.get(f"{kind}_footnote", [])))
            blocks.append(Block("figure", caption, page, bbox, image=item.get("img_path"), caption=caption))
        elif kind == "table":
            caption = _clean(" ".join(item.get("table_caption", [])))
            rows = table_rows(item.get("table_body", "")) + [
                f"Note: {_clean(note)}" for note in item.get("table_footnote", [])]
            text = "\n".join(([caption] if caption else []) + rows)
            blocks.append(Block("table", text, page, bbox, image=item.get("img_path"),
                                caption=caption, rows=tuple(rows)))
        elif kind == "equation":
            blocks.append(Block("equation", f"$$ {item['text']} $$", page, bbox, image=item.get("img_path")))
        elif kind == "list":
            text = "\n".join(_clean(entry) for entry in item.get("list_items", []) if _clean(entry))
            if text:
                blocks.append(Block("text", text, page, bbox))
        elif kind == "code":
            caption = _clean(" ".join(item.get("code_caption", [])))
            text = "\n".join(([caption] if caption else []) + [item.get("code_body", "")])
            blocks.append(Block("text", text.strip(), page, bbox))
        else:
            raise UnknownBlockType(f"MinerU produced a block of unknown type {kind!r} on page {page}")
    return blocks


def mineru_version() -> str:
    try:
        return version("mineru")
    except PackageNotFoundError as exc:
        raise MinerUMissing("MinerU is not installed in this environment; run `uv sync`") from exc


def parse_directory(cache_dir: Path, document_id: str, version: str, tier: str) -> Path:
    return cache_dir / document_id / f"{version}-{tier}"


def load_parsed(directory: Path) -> Parsed:
    meta = json.loads((directory / "meta.json").read_text(encoding="utf-8"))
    items = json.loads((directory / "content_list.json").read_text(encoding="utf-8"))
    return Parsed(
        directory=directory, title=meta.get("title"), authors=list(meta.get("authors") or []),
        created_at=meta.get("created_at"), pages=[tuple(p) for p in meta["pages"]],
        blocks=blocks_from_content_list(items),
    )


def parse_pdf(pdf: Path, document_id: str, *, cache_dir: Path, tier: str) -> Parsed:
    """Parse `pdf` with MinerU unless its parse directory already exists.

    MinerU writes into a temporary sibling directory that is renamed into
    place only when complete, so an interrupted parse is never mistaken for
    a cached one. The caller must run under `if __name__ == "__main__":`
    because MinerU starts its PDF render workers with `spawn`.
    """
    directory = parse_directory(cache_dir, document_id, mineru_version(), tier)
    if directory.exists():
        return load_parsed(directory)

    import mineru
    from mineru.parser import ParseResult
    from mineru.parser.writer import FileBasedDataWriter
    from mineru.render import render_content_list

    staging = directory.with_name(f"{directory.name}.tmp-{os.getpid()}")

```python
"""Blocks → chunks.

Slide decks give one chunk per page. Other documents are split into sections
at title blocks, and each section's blocks are packed greedily up to the token
budget. A block is never split, except a table larger than the budget, which
is split by rows with its header row repeated.
"""
from __future__ import annotations

from collections.abc import Callable
from dataclasses import dataclass
from itertools import groupby

from rag.parse import Block, Parsed

CHUNKER_VERSION = 1


@dataclass(frozen=True)
class Chunk:
    index: int
    kind: str
    text: str
    heading: str
    page_start: int
    page_end: int
    bboxes: list[list[int]]


@dataclass(frozen=True)
class _Part:
    kind: str
    text: str
    heading: str
    blocks: tuple[Block, ...]


def _block_text(block: Block) -> str:
    return block.caption if block.kind == "figure" else block.text


def _split_table(block: Block, max_tokens: int, count: Callable[[str], int]) -> list[str]:
    header, body = block.rows[0], block.rows[1:]
    pieces: list[list[str]] = [[]]
    prefix_first = ([block.caption] if block.caption else []) + [header]
    for row in body:
        prefix = prefix_first if len(pieces) == 1 else [header]
        candidate = prefix + pieces[-1] + [row]
        if pieces[-1] and count("\n".join(candidate)) > max_tokens:
            pieces.append([])
        pieces[-1].append(row)
    return ["\n".join((prefix_first if i == 0 else [header]) + rows) for i, rows in enumerate(pieces)]


def _pack(blocks: list[Block], heading: str, kind: str, max_tokens: int,
          count: Callable[[str], int]) -> list[_Part]:
    parts: list[_Part] = []
    current: list[Block] = []
    tokens = 0

    def flush():
        nonlocal current, tokens
        if current:
            only_tables = all(b.kind == "table" for b in current)
            parts.append(_Part("table" if kind == "text" and only_tables else kind,
                               "\n".join(_block_text(b) for b in current), heading, tuple(current)))
        current, tokens = [], 0

    for block in blocks:
        text = _block_text(block)
        if not text:
            continue
        n = count(text)
        if block.kind == "table" and n > max_tokens and len(block.rows) > 1:
            flush()
            for piece in _split_table(block, max_tokens, count):
                parts.append(_Part("table", piece, heading, (block,)))
            continue
        if current and tokens + n > max_tokens:
            flush()
        current.append(block)
        tokens += n
    flush()
    return parts


def _to_chunk(index: int, part: _Part) -> Chunk:
    pages = [b.page + 1 for b in part.blocks]
    return Chunk(index=index, kind=part.kind, text=part.text, heading=part.heading,
                 page_start=min(pages), page_end=max(pages),
                 bboxes=[[b.page + 1, *b.bbox] for b in part.blocks])


def chunk_document(parsed: Parsed, *, slides: bool, max_tokens: int,
                   count_tokens: Callable[[str], int]) -> list[Chunk]:
    parts: list[_Part] = []
    if slides:
        for _, page_blocks in groupby(parsed.blocks, key=lambda b: b.page):
            page_blocks = list(page_blocks)
            heading = next((b.text for b in page_blocks if b.kind == "title"), "")
            parts.extend(_pack(page_blocks, heading, "slide", max_tokens, count_tokens))
    else:
        heading, section = "", []
        for block in parsed.blocks:
            if block.kind == "title":
                parts.extend(_pack(section, heading, "text", max_tokens, count_tokens))
                heading, section = block.text, []
            else:
                section.append(block)
        parts.extend(_pack(section, heading, "text", max_tokens, count_tokens))
    return [_to_chunk(i, part) for i, part in enumerate(parts)]


def figure_chunks(parsed: Parsed, descriptions: dict[Block, str], *, start: int) -> list[Chunk]:
    chunks = []
    for offset, (block, description) in enumerate(descriptions.items()):
        page = block.page + 1
        text = f"{block.caption}\n\n{description}" if block.caption else description
        chunks.append(Chunk(index=start + offset, kind="figure", text=text,
                            heading=f"Figure on page {page}", page_start=page, page_end=page,
                            bboxes=[[page, *block.bbox]]))
    return chunks


def embedding_text(title: str, chunk: Chunk) -> str:
    header = f"{title} › {chunk.heading}" if chunk.heading else title
    return f"{header}\n{chunk.text}"
```

Note on the slide test: in slides mode a title block's text stays in the chunk text (it is part of the slide) and also becomes the heading; in prose mode title blocks only set the heading.

"""Document metadata from indico-rag manifests, MinerU output, and user overrides.

Precedence for every field: override, then manifest, then the document itself,
then a fallback (the filename for the title, "other" for the source type).
"""
from __future__ import annotations

import json
import re
from dataclasses import asdict, dataclass
from pathlib import Path

from rag.parse import Parsed

SOURCE_TYPES = ("talk", "paper", "thesis", "note", "other")
MANIFEST_NAME = "_manifest.json"

_GENERIC_TITLE = re.compile(
    r"^(powerpoint presentation|presentation|untitled.*|slide \d+|microsoft (word|powerpoint) - .*"
    r"|.*\.(pptx?|docx?|key|tex|pdf|odp))$",
    re.IGNORECASE,
)


class OldManifest(ValueError):
    pass


@dataclass(frozen=True)
class Overrides:
    source_type: str | None = None
    tags: tuple[str, ...] = ()
    title: str | None = None
    authors: tuple[str, ...] = ()
    date: str | None = None

    def __post_init__(self):
        if self.source_type is not None and self.source_type not in SOURCE_TYPES:
            raise ValueError(f"source_type must be one of {', '.join(SOURCE_TYPES)}, not {self.source_type!r}")

    @classmethod
    def from_args(cls, args: dict) -> "Overrides":
        return cls(source_type=args.get("source_type"), tags=tuple(args.get("tags") or ()),
                   title=args.get("title"), authors=tuple(args.get("authors") or ()), date=args.get("date"))

    def to_args(self) -> dict:
        return {k: list(v) if isinstance(v, tuple) else v for k, v in asdict(self).items()}


@dataclass(frozen=True)
class ManifestTalk:
    title: str
    speakers: list[str]
    session: str
    start: str | None
    indico_url: str
    event_id: str
    event_title: str


@dataclass(frozen=True)
class Metadata:
    title: str
    source_type: str
    authors: list[str]
    date: str | None
    tags: list[str]
    event_id: str | None
    event_title: str | None
    session: str | None
    indico_url: str | None
    slides: bool


def find_manifest_talk(pdf: Path, sha256: str, root: Path) -> ManifestTalk | None:
    """The manifest entry for this file's checksum, looking in the PDF's directory
    and its ancestors up to and including `root`."""
    root = root.resolve()
    directory = pdf.resolve().parent
    while True:
        manifest = directory / MANIFEST_NAME
        if manifest.exists():
            payload = json.loads(manifest.read_text(encoding="utf-8"))
            for record in payload.get("talks", {}).values():
                if record.get("sha256") != sha256:
                    continue
                event = payload.get("event")
                if event is None:
                    raise OldManifest(
                        f"{manifest} has no event block; re-run `indico-rag fetch` on that event "
                        "with a current indico-rag to add it (downloaded talks are skipped)")
                return ManifestTalk(
                    title=record["title"], speakers=list(record.get("speakers") or []),
                    session=record.get("session") or "", start=record.get("start"),
                    indico_url=event["host"] + record["indico_url"],
                    event_id=str(event["id"]), event_title=event["title"],
                )
        if directory == root or directory == directory.parent:
            return None
        directory = directory.parent


def _first_heading(parsed: Parsed) -> str | None:
    first_page = [b for b in parsed.blocks if b.kind == "title" and b.page == 0]
    if not first_page:
        return None
    return min(first_page, key=lambda b: b.level or 99).text


def _usable(title: str | None) -> str | None:
    if title and title.strip() and not _GENERIC_TITLE.match(title.strip()):
        return title.strip()
    return None


def resolve_metadata(pdf: Path, parsed: Parsed, talk: ManifestTalk | None,
                     overrides: Overrides) -> Metadata:
    title = (overrides.title or (talk.title if talk else None) or _usable(_first_heading(parsed))
             or _usable(parsed.title) or pdf.stem)
    source_type = overrides.source_type or ("talk" if talk else "other")
    authors = list(overrides.authors) or (talk.speakers if talk else []) or parsed.authors
    date = overrides.date or (talk.start if talk else None) or parsed.created_at
    return Metadata(
        title=title, source_type=source_type, authors=authors, date=date, tags=list(overrides.tags),
        event_id=talk.event_id if talk else None, event_title=talk.event_title if talk else None,
        session=talk.session if talk else None, indico_url=talk.indico_url if talk else None,
        slides=talk is not None or parsed.landscape,
    )
```

"""Dense and sparse (BM25) embeddings for chunks and queries."""
from __future__ import annotations

from qdrant_client import models

from rag.config import Config


class Embedder:
    dense_size: int

    def count_tokens(self, text: str) -> int:
        raise NotImplementedError

    def dense_documents(self, texts: list[str]) -> list[list[float]]:
        raise NotImplementedError

    def dense_query(self, text: str) -> list[float]:
        raise NotImplementedError

    def sparse_documents(self, texts: list[str]) -> list[models.SparseVector]:
        return [_sparse(e) for e in self._bm25.embed(texts)]

    def sparse_query(self, text: str) -> models.SparseVector:
        return _sparse(next(iter(self._bm25.query_embed(text))))


def _sparse(embedding) -> models.SparseVector:
    return models.SparseVector(indices=embedding.indices.tolist(), values=embedding.values.tolist())


def bm25(config: Config):
    from fastembed import SparseTextEmbedding

    return SparseTextEmbedding(config.sparse_model, cache_dir=str(config.models_dir))


class ModelEmbedder(Embedder):
    def __init__(self, config: Config):
        from sentence_transformers import SentenceTransformer

        self._model = SentenceTransformer(config.dense_model, device=config.device)
        self.dense_size = self._model.get_sentence_embedding_dimension()
        self._bm25 = bm25(config)

    def count_tokens(self, text: str) -> int:
        return len(self._model.tokenizer(text)["input_ids"])

    def dense_documents(self, texts: list[str]) -> list[list[float]]:
        return self._model.encode(texts, normalize_embeddings=True, batch_size=16).tolist()

    def dense_query(self, text: str) -> list[float]:
        return self._model.encode([text], prompt_name="query", normalize_embeddings=True)[0].tolist()
```

```python
"""The Qdrant collection: one point per chunk with a dense and a BM25 vector.

The collection's metadata records the settings it was built with; every
process compares them with its configuration before using the collection.
"""
from __future__ import annotations

import uuid

import httpx
from qdrant_client import QdrantClient, models
from qdrant_client.http.exceptions import ResponseHandlingException, UnexpectedResponse

from rag.chunk import CHUNKER_VERSION, Chunk
from rag.config import Config
from rag.embed import Embedder

DENSE = "dense"
SPARSE = "bm25"
_NAMESPACE = uuid.UUID("7d3c5b0e-6a2f-4f43-9c1e-2b8f6f0a9d41")

_KEYWORD_FIELDS = ("document_id", "source_type", "tags", "event_id", "kind")


class QdrantUnavailable(RuntimeError):
    pass


class SettingsMismatch(RuntimeError):
    pass


def index_settings(config: Config, dense_size: int) -> dict:
    return {"dense_model": config.dense_model, "dense_size": dense_size,
            "sparse_model": config.sparse_model, "chunker_version": CHUNKER_VERSION}


def point_id(document_id: str, chunk_index: int) -> str:
    return str(uuid.uuid5(_NAMESPACE, f"{document_id}:{chunk_index}:{CHUNKER_VERSION}"))


def build_points(document_id: str, chunks: list[Chunk], texts: list[str], payload_base: dict,
                 embedder: Embedder) -> list[models.PointStruct]:
    if not chunks:
        return []
    dense = embedder.dense_documents(texts)
    sparse = embedder.sparse_documents(texts)
    return [
        models.PointStruct(
            id=point_id(document_id, chunk.index),
            vector={DENSE: d, SPARSE: s},
            payload={**payload_base, "chunk_index": chunk.index, "kind": chunk.kind, "text": chunk.text,
                     "heading": chunk.heading, "page_start": chunk.page_start, "page_end": chunk.page_end,
                     "bboxes": chunk.bboxes},
        )
        for chunk, d, s in zip(chunks, dense, sparse, strict=True)
    ]


def _document_filter(document_id: str) -> models.Filter:
    return models.Filter(must=[models.FieldCondition(key="document_id", match=models.MatchValue(value=document_id))])


class Index:
    def __init__(self, config: Config, dense_size: int):
        self.url = config.qdrant_url
        self.name = config.collection
        self.settings = index_settings(config, dense_size)
        self.client = QdrantClient(url=config.qdrant_url, timeout=60)

    def _call(self, fn, *args, **kwargs):
        try:
            return fn(*args, **kwargs)
        except (ResponseHandlingException, httpx.TransportError) as exc:
            raise QdrantUnavailable(
                f"Qdrant is not reachable at {self.url} ({exc}); start it with "
                "`docker compose up -d` in the rag repository") from exc

    def ensure_collection(self) -> None:
        if not self._call(self.client.collection_exists, self.name):
            self._create()
            return
        stored = self._call(self.client.get_collection, self.name).config.metadata or {}
        differences = [f"{key}: collection has {stored.get(key)}, configuration has {value}"
                       for key, value in self.settings.items() if stored.get(key) != value]
        if differences:
            raise SettingsMismatch(
                f"collection {self.name!r} was built with different settings ("
                + "; ".join(differences) + "); run `rag rebuild` to re-index with the current configuration")

    def _create(self) -> None:
        self._call(
            self.client.create_collection, self.name,
            vectors_config={DENSE: models.VectorParams(size=self.settings["dense_size"],
                                                       distance=models.Distance.COSINE)},
            sparse_vectors_config={SPARSE: models.SparseVectorParams(modifier=models.Modifier.IDF)},
            metadata=self.settings,
        )
        for key in _KEYWORD_FIELDS:
            self._call(self.client.create_payload_index, self.name, key, models.PayloadSchemaType.KEYWORD)
        self._call(self.client.create_payload_index, self.name, "chunk_index", models.PayloadSchemaType.INTEGER)
        self._call(self.client.create_payload_index, self.name, "date", models.PayloadSchemaType.DATETIME)
        self._call(self.client.create_payload_index, self.name, "authors",
                   models.TextIndexParams(type=models.TextIndexType.TEXT, tokenizer=models.TokenizerType.WORD,
                                          lowercase=True))

    def delete_document(self, document_id: str) -> None:
        self._call(self.client.delete, self.name,
                   points_selector=models.FilterSelector(filter=_document_filter(document_id)), wait=True)

    def add_points(self, points: list[models.PointStruct]) -> None:
        for start in range(0, len(points), 64):
            self._call(self.client.upsert, self.name, points=points[start:start + 64], wait=True)

    def replace_document(self, document_id: str, points: list[models.PointStruct]) -> None:
        self.delete_document(document_id)
        self.add_points(points)

    def count(self, document_id: str | None = None) -> int:
        flt = _document_filter(document_id) if document_id else None
        return self._call(self.client.count, self.name, count_filter=flt, exact=True).count

    def chunk(self, chunk_id: str) -> dict | None:
        try:
            records = self._call(self.client.retrieve, self.name, ids=[chunk_id], with_payload=True)
        except UnexpectedResponse:
            return None
        return {"id": str(records[0].id), **records[0].payload} if records else None

    def neighbors(self, document_id: str, chunk_index: int, before: int, after: int) -> list[dict]:
        flt = models.Filter(must=[
            models.FieldCondition(key="document_id", match=models.MatchValue(value=document_id)),
            models.FieldCondition(key="chunk_index", range=models.Range(gte=chunk_index - before,
                                                                        lte=chunk_index + after)),
        ])
        records, _ = self._call(self.client.scroll, self.name, scroll_filter=flt, limit=before + after + 1,
                                with_payload=True)
        return sorted(({"id": str(r.id), **r.payload} for r in records), key=lambda p: p["chunk_index"])

    def query(self, dense: list[float], sparse: models.SparseVector, query_filter: models.Filter | None,
              limit: int) -> list[models.ScoredPoint]:
        response = self._call(
            self.client.query_points, self.name,
            prefetch=[models.Prefetch(query=dense, using=DENSE, filter=query_filter, limit=50),
                      models.Prefetch(query=sparse, using=SPARSE, filter=query_filter, limit=50)],
            query=models.FusionQuery(fusion=models.Fusion.RRF), limit=limit, with_payload=True,
        )
        return response.points

    def drop(self) -> None:
        if self._call(self.client.collection_exists, self.name):
            self._call(self.client.delete_collection, self.name)
```

```python
"""Figure descriptions from a vision model served by Ollama."""
from __future__ import annotations

import base64
import hashlib
from collections import defaultdict
from pathlib import Path

import httpx

from rag.config import Config
from rag.parse import Block, Parsed

_MIN_AREA = 20_000  # 2 % of a page, in MinerU's 0–1000 × 0–1000 bbox units
_REPEATS = 3
_PROMPT = (
    "This image is a figure from a physics document. Describe what it shows in two to four "
    "sentences: the kind of plot or diagram, the quantities on its axes, and the main result "
    "it conveys. Do not speculate beyond what is visible.\n\nCaption: "
)


class VisionUnavailable(RuntimeError):
    pass


def check_vision(config: Config) -> None:
    try:
        response = httpx.get(f"{config.ollama_url}/api/tags", timeout=5)
        response.raise_for_status()
    except httpx.HTTPError as exc:
        raise VisionUnavailable(f"Ollama is not reachable at {config.ollama_url} ({exc}); start Ollama") from exc
    names = {m["name"] for m in response.json().get("models", [])}
    if config.vision_model not in names:
        raise VisionUnavailable(
            f"the vision model {config.vision_model} is not available in Ollama; "
            f"run `ollama pull {config.vision_model}` or set vision_model in the configuration")


def figures_worth_describing(parsed: Parsed) -> list[Block]:
    candidates = [b for b in parsed.blocks if b.kind == "figure" and b.image is not None]
    pages_by_digest: dict[str, set[int]] = defaultdict(set)
    digests: dict[Block, str] = {}
    for block in candidates:
        digest = hashlib.sha256(parsed.image_path(block).read_bytes()).hexdigest()
        digests[block] = digest
        pages_by_digest[digest].add(block.page)
    chosen = []
    for block in candidates:
        x0, y0, x1, y1 = block.bbox
        if (x1 - x0) * (y1 - y0) < _MIN_AREA:
            continue
        if len(pages_by_digest[digests[block]]) >= _REPEATS:
            continue
        chosen.append(block)
    return chosen


def describe_figure(image: Path, caption: str, *, config: Config, client: httpx.Client) -> str:
    payload = {
        "model": config.vision_model,
        "stream": False,
        "think": False,
        "messages": [{"role": "user", "content": _PROMPT + (caption or "(none)"),
                      "images": [base64.b64encode(image.read_bytes()).decode()]}],
    }
    try:
        response = client.post(f"{config.ollama_url}/api/chat", json=payload, timeout=300)
    except httpx.TransportError as exc:
        raise VisionUnavailable(f"Ollama is not reachable at {config.ollama_url} ({exc})") from exc
    response.raise_for_status()
    return response.json()["message"]["content"].strip()


def describe_figures(parsed: Parsed, config: Config) -> dict[Block, str]:
    with httpx.Client() as client:
        return {block: describe_figure(parsed.image_path(block), block.caption, config=config, client=client)
                for block in figures_worth_describing(parsed)}
```

"""The per-document pipeline: hash → parse → metadata → chunk → [enrich] → embed → write."""
from __future__ import annotations

import hashlib
import json
from collections.abc import Callable
from functools import cached_property
from pathlib import Path

from rag.catalog import Catalog, Document
from rag.chunk import chunk_document, embedding_text, figure_chunks
from rag.config import Config
from rag.embed import Embedder
from rag.enrich import VisionUnavailable, check_vision, describe_figures
from rag.index import Index, QdrantUnavailable, SettingsMismatch, build_points, index_settings
from rag.metadata import Metadata, Overrides, find_manifest_talk, resolve_metadata
from rag.parse import MinerUMissing, Parsed, load_parsed, mineru_version, parse_directory, parse_pdf

ABORTING = (QdrantUnavailable, SettingsMismatch, VisionUnavailable, MinerUMissing)

Stage = Callable[[str], None]


class Services:
    """Configuration plus the catalog, embedder, index and parser one process uses.

    The embedder and the index are created on first use, so commands that only
    read the catalog never load a model or contact Qdrant. `embedder` and
    `parser` can be supplied to replace the model and MinerU.
    """

    def __init__(self, config: Config, *, embedder: Embedder | None = None,
                 parser: Callable[[Path, str], Parsed] | None = None):
        self.config = config
        self.catalog = Catalog(config.catalog_path)
        self._embedder = embedder
        self.parser = parser

    @cached_property
    def embedder(self) -> Embedder:
        if self._embedder is not None:
            return self._embedder
        from rag.embed import ModelEmbedder

        return ModelEmbedder(self.config)

    @cached_property
    def index(self) -> Index:
        index = Index(self.config, self.embedder.dense_size)
        index.ensure_collection()
        return index

    def parse(self, pdf: Path, document_id: str) -> Parsed:
        if self.parser is not None:
            return self.parser(pdf, document_id)
        return parse_pdf(pdf, document_id, cache_dir=self.config.cache_dir, tier=self.config.mineru_tier)

    def load_cached(self, document_id: str) -> Parsed:
        """The cached MinerU output of an already-parsed document; MinerU is not run."""
        if self.parser is not None:
            doc = self.catalog.get_document(document_id)
            return self.parser(Path(doc.paths[0]), document_id)
        return load_parsed(parse_directory(self.config.cache_dir, document_id, mineru_version(),
                                           self.config.mineru_tier))

    def settings(self) -> str:
        """Everything that, when changed, makes an indexed document out of date."""
        return json.dumps({"mineru": mineru_version(), "tier": self.config.mineru_tier,
                           **index_settings(self.config, self.embedder.dense_size)}, sort_keys=True)


def sha256_of(path: Path) -> str:
    digest = hashlib.sha256()
    with path.open("rb") as handle:
        for block in iter(lambda: handle.read(1 << 20), b""):
            digest.update(block)
    return digest.hexdigest()


def discover(path: Path) -> tuple[list[Path], list[Path]]:
    """PDFs under `path` and the other files there (hidden files and manifests excluded)."""
    if not path.exists():
        raise FileNotFoundError(f"no such file or directory: {path}")
    if path.is_file():
        return ([path], []) if path.suffix.lower() == ".pdf" else ([], [path])
    files = sorted(p for p in path.rglob("*") if p.is_file() and not p.name.startswith("."))
    pdfs = [p for p in files if p.suffix.lower() == ".pdf"]
    others = [p for p in files if p.suffix.lower() != ".pdf" and p.name != "_manifest.json"]
    return pdfs, others


def _document(document_id: str, meta: Metadata, parsed: Parsed, enrich: bool) -> Document:
    return Document(id=document_id, title=meta.title, source_type=meta.source_type, authors=meta.authors,
                    date=meta.date, tags=meta.tags, event_id=meta.event_id, event_title=meta.event_title,
                    session=meta.session, indico_url=meta.indico_url, enrich=enrich, status="pending",
                    settings=None, page_count=len(parsed.pages), error=None)


def _payload_base(doc: Document) -> dict:
    return {"document_id": doc.id, "title": doc.title, "source_type": doc.source_type,
            "authors": doc.authors, "date": doc.date, "tags": doc.tags, "event_id": doc.event_id,
            "event_title": doc.event_title, "session": doc.session, "indico_url": doc.indico_url}


def _slides(doc: Document, parsed: Parsed) -> bool:
    return doc.source_type == "talk" or parsed.landscape


def _index_document(doc: Document, parsed: Parsed, slides: bool, services: Services, stage: Stage) -> None:
    stage("chunk")
    chunks = chunk_document(parsed, slides=slides, max_tokens=services.config.chunk_tokens,
                            count_tokens=services.embedder.count_tokens)
    if doc.enrich:
        stage("enrich")
        check_vision(services.config)
        chunks += figure_chunks(parsed, describe_figures(parsed, services.config), start=len(chunks))
    stage("embed")
    texts = [embedding_text(doc.title, c) for c in chunks]
    points = build_points(doc.id, chunks, texts, _payload_base(doc), services.embedder)
    stage("write")
    services.index.replace_document(doc.id, points)
    services.catalog.set_status(doc.id, "indexed", settings=services.settings())


def ingest_file(pdf: Path, *, root: Path, overrides: Overrides, enrich: bool, services: Services,
                stage: Stage) -> tuple[str, bool]:
    """Index one PDF; returns its document id and whether it was already up to date.

    A file whose path previously belonged to another checksum replaces that
    document once no other path refers to it.
    """
    pdf = pdf.resolve()
    stage("hash")
    document_id = sha256_of(pdf)
    catalog = services.catalog
    previous = catalog.documents_for_path(str(pdf))
    existing = catalog.get_document(document_id)
    if (existing and existing.status == "indexed" and existing.settings == services.settings()
            and (existing.enrich or not enrich)):
        catalog.add_path(str(pdf), document_id)
        return document_id, True

    stage("parse")
    parsed = services.parse(pdf, document_id)
    stage("metadata")
    talk = find_manifest_talk(pdf, document_id, root=root)
    meta = resolve_metadata(pdf, parsed, talk, overrides)
    catalog.put_document(_document(document_id, meta, parsed, enrich or bool(existing and existing.enrich)))
    catalog.add_path(str(pdf), document_id)
    if previous and previous != document_id:
        old = catalog.get_document(previous)
        if old is not None and not old.paths:
            remove_document(previous, services)
    _index_document(catalog.get_document(document_id), parsed, meta.slides, services, stage)
    return document_id, False


def enrich_document(document_id: str, services: Services, stage: Stage) -> None:
    doc = services.catalog.get_document(document_id)
    if doc is None:
        raise KeyError(f"no document {document_id}")
    doc.enrich = True
    services.catalog.put_document(doc)
    parsed = services.load_cached(document_id)
    _index_document(doc, parsed, _slides(doc, parsed), services, stage)


def remove_document(document_id: str, services: Services) -> None:
    services.index.delete_document(document_id)
    services.catalog.delete_document(document_id)


def rebuild(services: Services, report: Callable[[str], None]) -> list[tuple[str, str]]:
    """Drop the collection and re-index every catalogued document from the MinerU cache."""
    services.index.drop()
    del services.index
    failures = []
    for doc in services.catalog.list_documents():
        report(f"{doc.title} ({doc.id[:12]})")
        try:
            parsed = services.load_cached(doc.id)
            _index_document(doc, parsed, _slides(doc, parsed), services, stage=lambda s: None)
        except ABORTING:
            raise
        except Exception as exc:
            error = f"{type(exc).__name__}: {exc}"
            services.catalog.set_status(doc.id, "failed", error=error)
            failures.append((doc.id, error))
    return failures
```

"""Ingest jobs: queued in the catalog, run one at a time by a single worker.

The worker is a detached process so a job outlives the MCP server or the
terminal that started it. Jobs run serially because MinerU, the embedding
model and the vision model share one GPU.
"""
from __future__ import annotations

import os
import subprocess
import sys
from collections.abc import Callable
from pathlib import Path

from rag.catalog import Catalog, Job
from rag.config import Config, config_path
from rag.ingest import ABORTING, Services, discover, enrich_document, ingest_file
from rag.metadata import Overrides

Progress = Callable[[str], None]


class WorkerBusy(RuntimeError):
    pass


def submit_add(catalog: Catalog, path: Path, overrides: Overrides, enrich: bool) -> int:
    path = path.expanduser().resolve()
    if not path.exists():
        raise FileNotFoundError(f"no such file or directory: {path}")
    return catalog.create_job("add", {"path": str(path), "enrich": enrich, "overrides": overrides.to_args()})


def submit_enrich(catalog: Catalog, document_ids: list[str]) -> int:
    missing = [d for d in document_ids if catalog.get_document(d) is None]
    if missing:
        raise KeyError(f"no documents with ids {', '.join(missing)}")
    return catalog.create_job("enrich", {"document_ids": document_ids})


def _error(exc: BaseException) -> str:
    return f"{type(exc).__name__}: {exc}"


def _run_add(job: Job, services: Services, progress: Progress) -> bool:
    catalog = services.catalog
    root = Path(job.args["path"])
    overrides = Overrides.from_args(job.args["overrides"])
    pdfs, others = discover(root)
    for path in pdfs + others:
        catalog.add_job_file(job.id, str(path))
    for path in others:
        catalog.update_job_file(job.id, str(path), stage="discover", status="skipped",
                                error="not a PDF")
    done = {f.path for f in catalog.job_files(job.id) if f.status == "done"}
    failed = False
    for number, pdf in enumerate(pdfs, start=1):
        if str(pdf) in done:
            continue
        current = {"stage": "hash"}

        def stage(name: str) -> None:
            current["stage"] = name
            catalog.update_job_file(job.id, str(pdf), stage=name, status="pending")
            progress(f"[{number}/{len(pdfs)}] {pdf.name}: {name}")

        try:
            document_id, skipped = ingest_file(pdf, root=root if root.is_dir() else root.parent,
                                               overrides=overrides, enrich=job.args["enrich"],
                                               services=services, stage=stage)
        except ABORTING:
            raise
        except Exception as exc:
            failed = True
            catalog.update_job_file(job.id, str(pdf), stage=current["stage"], status="failed", error=_error(exc))
            progress(f"[{number}/{len(pdfs)}] {pdf.name}: failed at {current['stage']}: {_error(exc)}")
            continue
        catalog.update_job_file(job.id, str(pdf), stage="skipped-unchanged" if skipped else "write",
                                status="done", document_id=document_id)
    return failed


def _run_enrich(job: Job, services: Services, progress: Progress) -> bool:
    failed = False
    for document_id in job.args["document_ids"]:
        services.catalog.add_job_file(job.id, document_id)
        try:
            enrich_document(document_id, services,
                            stage=lambda name: progress(f"{document_id[:12]}: {name}"))
        except ABORTING:
            raise
        except Exception as exc:
            failed = True
            services.catalog.update_job_file(job.id, document_id, stage="enrich", status="failed",
                                             error=_error(exc))
            continue
        services.catalog.update_job_file(job.id, document_id, stage="write", status="done",
                                         document_id=document_id)
    return failed


def run_job(job: Job, services: Services, progress: Progress = lambda m: None) -> str:
    catalog = services.catalog
    catalog.start_job(job.id, os.getpid())
    try:
        runner = {"add": _run_add, "enrich": _run_enrich}[job.kind]
        failed = runner(job, services, progress)
    except ABORTING as exc:
        catalog.finish_job(job.id, "failed", _error(exc))
        progress(f"job {job.id} stopped: {_error(exc)}")
        return "failed"
    status = "completed_with_failures" if failed else "completed"
    catalog.finish_job(job.id, status)
    return status


def run_worker(services: Services, progress: Progress = lambda m: None) -> int:
    catalog = services.catalog
    pid = os.getpid()
    if not catalog.acquire_worker(pid):
        return 0
    ran = 0
    try:
        catalog.requeue_dead_jobs()
        while (job := catalog.next_queued_job()) is not None:
            run_job(job, services, progress)
            ran += 1
    finally:
        catalog.release_worker(pid)
    return ran


def run_foreground(job_id: int, services: Services, progress: Progress) -> str:
    catalog = services.catalog
    pid = os.getpid()
    if not catalog.acquire_worker(pid):
        raise WorkerBusy(
            f"a background worker (pid {catalog.worker_pid()}) is running; "
            f"job {job_id} is queued and will run after it, or use --background")
    try:
        return run_job(catalog.get_job(job_id), services, progress)
    finally:
        catalog.release_worker(pid)


def spawn_worker(config: Config) -> None:
    config.data_dir.mkdir(parents=True, exist_ok=True)
    env = {**os.environ, "RAG_CONFIG": str(config_path())}
    with config.log_path.open("ab") as log:
        subprocess.Popen([sys.executable, "-m", "rag", "worker"], stdin=subprocess.DEVNULL, stdout=log,
                         stderr=subprocess.STDOUT, start_new_session=True, env=env)
```

```python
"""Hybrid search: dense and BM25 candidates under the same filter, fused by RRF."""
from __future__ import annotations

from dataclasses import asdict, dataclass, field
from pathlib import Path
from urllib.parse import quote

from qdrant_client import models

from rag.ingest import Services

_CANDIDATES = 100


@dataclass
class Filters:
    source_type: str | None = None
    tags: list[str] = field(default_factory=list)
    event: str | None = None
    authors: list[str] = field(default_factory=list)
    date_from: str | None = None
    date_to: str | None = None
    document_id: str | None = None


@dataclass
class Hit:
    chunk_id: str
    document_id: str
    score: float
    kind: str
    text: str
    heading: str
    title: str
    source_type: str
    authors: list[str]
    date: str | None
    event_title: str | None
    page_start: int
    page_end: int
    path: str | None
    link: str | None

    def to_dict(self) -> dict:
        return asdict(self)


def build_filter(filters: Filters) -> models.Filter | None:
    must: list[models.Condition] = []
    if filters.source_type:
        must.append(models.FieldCondition(key="source_type", match=models.MatchValue(value=filters.source_type)))
    if filters.tags:
        must.append(models.FieldCondition(key="tags", match=models.MatchAny(any=filters.tags)))
    if filters.event:
        must.append(models.FieldCondition(key="event_id", match=models.MatchValue(value=filters.event)))
    if filters.document_id:
        must.append(models.FieldCondition(key="document_id", match=models.MatchValue(value=filters.document_id)))
    if filters.date_from or filters.date_to:
        must.append(models.FieldCondition(key="date", range=models.DatetimeRange(
            gte=filters.date_from, lte=filters.date_to)))
    if filters.authors:
        must.append(models.Filter(should=[
            models.FieldCondition(key="authors", match=models.MatchText(text=name)) for name in filters.authors]))
    return models.Filter(must=must) if must else None


def _existing_path(services: Services, document_id: str) -> str | None:
    doc = services.catalog.get_document(document_id)
    if doc is None:
        return None
    return next((p for p in doc.paths if Path(p).exists()), None)


def _hit(services: Services, chunk_id: str, score: float, payload: dict, paths: dict[str, str | None]) -> Hit:
    document_id = payload["document_id"]
    if document_id not in paths:
        paths[document_id] = _existing_path(services, document_id)
    path = paths[document_id]
    link = payload.get("indico_url") or (f"file://{quote(path)}#page={payload['page_start']}" if path else None)
    return Hit(chunk_id=chunk_id, document_id=document_id, score=score, kind=payload["kind"],
               text=payload["text"], heading=payload.get("heading", ""), title=payload["title"],
               source_type=payload["source_type"], authors=payload.get("authors", []), date=payload.get("date"),
               event_title=payload.get("event_title"), page_start=payload["page_start"],
               page_end=payload["page_end"], path=path, link=link)


def search(services: Services, query: str, filters: Filters | None = None, *, limit: int = 8,
           max_per_document: int = 3) -> list[Hit]:
    embedder = services.embedder
    points = services.index.query(embedder.dense_query(query), embedder.sparse_query(query),
                                  build_filter(filters or Filters()), limit=_CANDIDATES)
    per_document: dict[str, int] = {}
    paths: dict[str, str | None] = {}
    hits = []
    for point in points:
        document_id = point.payload["document_id"]
        if per_document.get(document_id, 0) >= max_per_document:
            continue
        per_document[document_id] = per_document.get(document_id, 0) + 1
        hits.append(_hit(services, str(point.id), point.score, point.payload, paths))
        if len(hits) == limit:
            break
    return hits


def context(services: Services, chunk_id: str, before: int = 1, after: int = 1) -> list[Hit]:
    center = services.index.chunk(chunk_id)
    if center is None:
        raise KeyError(f"no chunk {chunk_id}")
    paths: dict[str, str | None] = {}
    return [_hit(services, p["id"], 0.0, p, paths)
            for p in services.index.neighbors(center["document_id"], center["chunk_index"], before, after)]
```

"""Checks that the services rag depends on are present and consistent."""
from __future__ import annotations

import shutil
from pathlib import Path

from rag.config import Config


def run_checks(config: Config) -> list[tuple[str, bool, str]]:
    results: list[tuple[str, bool, str]] = []

    def check(name, fn):
        try:
            results.append((name, True, fn() or "ok"))
        except Exception as exc:
            results.append((name, False, f"{type(exc).__name__}: {exc}"))

    def qdrant():
        from rag.embed import ModelEmbedder
        from rag.index import Index
        Index(config, ModelEmbedder(config).dense_size).ensure_collection()
        return f"{config.qdrant_url}, collection {config.collection!r} matches the configuration"

    def mineru():
        from rag.parse import mineru_version
        models = Path.home() / ".mineru" / "models"
        if not models.exists():
            raise FileNotFoundError(f"{models} is missing; run `uv run mineru-kit models download --tier "
                                    f"{config.mineru_tier} --source huggingface`")
        return f"mineru {mineru_version()}, models in {models}"

    def ollama():
        from rag.enrich import check_vision
        check_vision(config)
        return f"{config.vision_model} at {config.ollama_url}"

    def disk():
        config.data_dir.mkdir(parents=True, exist_ok=True)
        free = shutil.disk_usage(config.data_dir).free / 1e9
        if free < 20:
            raise RuntimeError(f"only {free:.0f} GB free under {config.data_dir}")
        return f"{free:.0f} GB free"

    check("mineru", mineru)
    check("qdrant", qdrant)
    check("ollama (only needed for --enrich)", ollama)
    check("disk", disk)
    return results

```python
"""The `rag` command line."""
from __future__ import annotations

import argparse
import sys
from pathlib import Path

from rag.config import load_config
from rag.ingest import ABORTING, Services, rebuild, remove_document
from rag.jobs import WorkerBusy, run_foreground, run_worker, spawn_worker, submit_add, submit_enrich
from rag.metadata import SOURCE_TYPES, Overrides
from rag.search import Filters, search


def make_services() -> Services:
    return Services(load_config())


def _resolve_document(services: Services, prefix: str) -> str:
    matches = [d.id for d in services.catalog.list_documents() if d.id.startswith(prefix)]
    if len(matches) != 1:
        raise KeyError(f"no document with id {prefix!r}" if not matches
                       else f"id prefix {prefix!r} is ambiguous ({len(matches)} documents)")
    return matches[0]


def _cmd_add(args, services: Services) -> int:
    overrides = Overrides(source_type=args.type, tags=tuple(args.tag), title=args.title,
                          authors=tuple(args.author), date=args.date)
    job = submit_add(services.catalog, Path(args.path), overrides, enrich=args.enrich)
    if args.background:
        spawn_worker(services.config)
        print(f"queued as job {job}; follow it with `rag status {job}`")
        return 0
    status = run_foreground(job, services, progress=lambda m: print(m, file=sys.stderr))
    _print_job(services, job)
    return 1 if status == "failed" else 0


def _print_job(services: Services, job_id: int) -> int:
    job = services.catalog.get_job(job_id)
    files = services.catalog.job_files(job_id)
    indexed = sum(f.status == "done" and f.stage != "skipped-unchanged" for f in files)
    unchanged = sum(f.stage == "skipped-unchanged" for f in files)
    failed = [f for f in files if f.status == "failed"]
    others = [f for f in files if f.status == "skipped"]
    print(f"job {job.id} ({job.kind}) {job.status}: {indexed} indexed, {unchanged} skipped, {len(failed)} failed")
    if job.interruptions:
        print(f"  resumed after {job.interruptions} interruption(s)")
    if job.error:
        print(f"  error: {job.error}")
    for f in failed:
        print(f"  FAILED {f.path} at {f.stage}: {f.error}")
    for f in others:
        print(f"  not indexed: {f.path} ({f.error})")
    return 0


def _cmd_search(args, services: Services) -> int:
    filters = Filters(source_type=args.type, tags=args.tag, event=args.event, authors=args.author,
                      date_from=args.since, date_to=args.until)
    for n, hit in enumerate(search(services, args.query, filters, limit=args.limit), start=1):
        pages = f"p. {hit.page_start}" if hit.page_start == hit.page_end else f"pp. {hit.page_start}–{hit.page_end}"
        print(f"{n}. {hit.title} — {pages} [{hit.source_type}] {hit.link or ''}")
        print("   " + hit.text[:300].replace("\n", " "))
    return 0


def _cmd_status(args, services: Services) -> int:
    if args.job is not None:
        return _print_job(services, args.job)
    worker = services.catalog.worker_pid()
    print(f"worker: {'running (pid %d)' % worker if worker else 'idle'}")
    for job in services.catalog.recent_jobs():
        print(f"job {job.id} {job.kind} {job.status} {job.args.get('path', '')}")
    docs = services.catalog.list_documents()
    print(f"{len(docs)} documents, {sum(d.status == 'indexed' for d in docs)} indexed")
    for doc in docs:
        if not any(Path(p).exists() for p in doc.paths):
            print(f"  missing on disk: {doc.title} ({doc.id[:12]}) {doc.paths}")
        if doc.status == "failed":
            print(f"  failed: {doc.title} ({doc.id[:12]}): {doc.error}")
    return 0


def _cmd_enrich(args, services: Services) -> int:
    ids = [_resolve_document(services, p) for p in args.documents]
    job = submit_enrich(services.catalog, ids)
    spawn_worker(services.config)
    print(f"queued as job {job}; follow it with `rag status {job}`")
    return 0


def _cmd_rm(args, services: Services) -> int:
    document_id = _resolve_document(services, args.document)
    title = services.catalog.get_document(document_id).title
    remove_document(document_id, services)
    print(f"removed {title} ({document_id[:12]})")
    return 0


def _cmd_rebuild(args, services: Services) -> int:
    failures = rebuild(services, report=lambda m: print(m, file=sys.stderr))
    for document_id, error in failures:
        print(f"FAILED {document_id[:12]}: {error}")
    return 1 if failures else 0


def _cmd_doctor(args, services: Services) -> int:
    from rag.doctor import run_checks
    results = run_checks(services.config)
    for name, ok, detail in results:
        print(f"{'ok  ' if ok else 'FAIL'} {name}: {detail}")
    return 0 if all(ok for name, ok, _ in results if not name.startswith("ollama")) else 1


def _cmd_worker(args, services: Services) -> int:
    run_worker(services, progress=lambda m: print(m, flush=True))
    return 0


def _parser() -> argparse.ArgumentParser:
    parser = argparse.ArgumentParser(prog="rag", description="Hybrid search over a PDF library.")
    sub = parser.add_subparsers(dest="command", required=True)

    p = sub.add_parser("add", help="index a PDF or a folder of PDFs")
    p.add_argument("path")
    p.add_argument("--type", choices=SOURCE_TYPES)
    p.add_argument("--tag", action="append", default=[])
    p.add_argument("--title")
    p.add_argument("--author", action="append", default=[])
    p.add_argument("--date", help="ISO 8601 date")
    p.add_argument("--enrich", action="store_true", help="describe figures with the vision model")
    p.add_argument("--background", action="store_true", help="queue the job and return")
    p.set_defaults(fn=_cmd_add)

    p = sub.add_parser("search", help="search the index")
    p.add_argument("query")
    p.add_argument("--type", choices=SOURCE_TYPES)
    p.add_argument("--tag", action="append", default=[])
    p.add_argument("--event", help="Indico event id")
    p.add_argument("--author", action="append", default=[])
    p.add_argument("--since", help="ISO 8601 date")
    p.add_argument("--until", help="ISO 8601 date")
    p.add_argument("--limit", type=int, default=8)
    p.set_defaults(fn=_cmd_search)

    p = sub.add_parser("status", help="jobs, failures, and documents missing on disk")
    p.add_argument("job", nargs="?", type=int)
    p.set_defaults(fn=_cmd_status)

    p = sub.add_parser("enrich", help="add figure descriptions to indexed documents")
    p.add_argument("documents", nargs="+", help="document ids or unique prefixes")
    p.set_defaults(fn=_cmd_enrich)

    p = sub.add_parser("rm", help="remove a document from the catalog and the index")
    p.add_argument("document", help="document id or unique prefix")
    p.set_defaults(fn=_cmd_rm)

    sub.add_parser("rebuild", help="re-index everything from the MinerU cache").set_defaults(fn=_cmd_rebuild)
    sub.add_parser("doctor", help="check Qdrant, MinerU, Ollama and disk").set_defaults(fn=_cmd_doctor)
    sub.add_parser("worker", help=argparse.SUPPRESS).set_defaults(fn=_cmd_worker)
    return parser


def main(argv: list[str] | None = None) -> int:
    args = _parser().parse_args(argv)
    services = make_services()
    try:
        return args.fn(args, services)
    except (FileNotFoundError, KeyError, ValueError, WorkerBusy) as exc:
        message = exc.args[0] if isinstance(exc, KeyError) and exc.args else exc
        print(f"error: {message}", file=sys.stderr)
        return 2
    except ABORTING as exc:
        print(f"error: {exc}", file=sys.stderr)
        return 1
```

```python
"""MCP tools over the index, the catalog and the job queue (stdio transport)."""
from __future__ import annotations

from collections.abc import Callable
from dataclasses import asdict
from functools import cache
from pathlib import Path

from mcp.server.mcpserver import MCPServer

from rag.ingest import Services, remove_document as _remove
from rag.jobs import spawn_worker, submit_add, submit_enrich
from rag.metadata import Overrides
from rag.search import Filters, context, search as _search

_INSTRUCTIONS = (
    "Search a personal library of physics PDFs: conference talks from Indico, papers, theses and notes. "
    "Use `search` first; cite results by title and page and give the link. Use `read_context` when a "
    "result is cut off. Adding documents runs in the background: `add_documents` returns a job id to "
    "pass to `ingest_status`."
)


def build_server(make_services: Callable[[], Services]) -> MCPServer:
    services = cache(make_services)
    server = MCPServer("rag", instructions=_INSTRUCTIONS)

    @server.tool()
    def search(query: str, limit: int = 8, source_type: str | None = None, tags: list[str] | None = None,
               event: str | None = None, authors: list[str] | None = None, date_from: str | None = None,
               date_to: str | None = None, document_id: str | None = None,
               max_per_document: int = 3) -> list[dict]:
        """Hybrid (semantic + keyword) search. source_type is one of talk, paper, thesis, note, other;
        event is an Indico event id; dates are ISO 8601. Returns chunks with title, pages and a link."""
        filters = Filters(source_type=source_type, tags=tags or [], event=event, authors=authors or [],
                          date_from=date_from, date_to=date_to, document_id=document_id)
        return [h.to_dict() for h in _search(services(), query, filters, limit=limit,
                                              max_per_document=max_per_document)]

    @server.tool()
    def read_context(chunk_id: str, before: int = 1, after: int = 1) -> list[dict]:
        """The chunks before and after a search result, in document order."""
        return [h.to_dict() for h in context(services(), chunk_id, before, after)]

    @server.tool()
    def get_document(document_id: str) -> dict:
        """A document's metadata, status and file paths."""
        doc = services().catalog.get_document(document_id)
        if doc is None:
            raise ValueError(f"no document {document_id}")
        return asdict(doc)

    @server.tool()
    def list_documents(source_type: str | None = None, tag: str | None = None,
                       event: str | None = None) -> list[dict]:
        """Catalogued documents, optionally filtered; each with id, title, type, date, event and status."""
        docs = services().catalog.list_documents(source_type=source_type, tag=tag, event_id=event)
        return [{"id": d.id, "title": d.title, "source_type": d.source_type, "date": d.date,
                 "event_title": d.event_title, "tags": d.tags, "status": d.status} for d in docs]

    @server.tool()
    def add_documents(path: str, source_type: str | None = None, tags: list[str] | None = None,
                      enrich: bool = False) -> dict:
        """Queue a PDF or a folder of PDFs for indexing in the background. enrich=true also describes
        figures with a vision model (about 30 s per figure). Returns a job id for ingest_status."""
        overrides = Overrides(source_type=source_type, tags=tuple(tags or ()))
        job_id = submit_add(services().catalog, Path(path), overrides, enrich=enrich)
        spawn_worker(services().config)
        return {"job_id": job_id}

    @server.tool()
    def ingest_status(job_id: int | None = None) -> dict:
        """Progress of one job (counts, the file being processed, every failure with its error),
        or the ten most recent jobs when job_id is omitted."""
        catalog = services().catalog
        if job_id is None:
            return {"jobs": [{"id": j.id, "kind": j.kind, "status": j.status, "path": j.args.get("path")}
                             for j in catalog.recent_jobs()]}
        job = catalog.get_job(job_id)
        if job is None:
            raise ValueError(f"no job {job_id}")
        files = catalog.job_files(job_id)
        return {
            "id": job.id, "status": job.status, "error": job.error, "interruptions": job.interruptions,
            "total": len(files), "done": sum(f.status == "done" for f in files),
            "in_progress": [{"path": f.path, "stage": f.stage} for f in files
                            if f.status == "pending" and f.stage != "queued"],
            "failed": [{"path": f.path, "stage": f.stage, "error": f.error} for f in files if f.status == "failed"],
            "not_indexed": [{"path": f.path, "reason": f.error} for f in files if f.status == "skipped"],
        }

    @server.tool()
    def enrich(document_ids: list[str]) -> dict:
        """Queue figure descriptions for already indexed documents. Returns a job id."""
        job_id = submit_enrich(services().catalog, document_ids)
        spawn_worker(services().config)
        return {"job_id": job_id}

    @server.tool()
    def remove_document(document_id: str) -> dict:
        """Remove a document from the catalog and the index. The PDF on disk is not touched."""
        if services().catalog.get_document(document_id) is None:
            raise ValueError(f"no document {document_id}")
        _remove(document_id, services())
        return {"removed": document_id}

    return server


def serve() -> None:
    from rag.config import load_config
    build_server(lambda: Services(load_config())).run(transport="stdio")
```

```python
"""Retrieval quality over a set of questions with known answers."""
from __future__ import annotations

import json
from dataclasses import dataclass
from pathlib import Path

from rag.ingest import Services, sha256_of
from rag.search import search


@dataclass(frozen=True)
class Question:
    question: str
    document: str
    page: int | None


@dataclass
class Report:
    recall: dict[int, float]
    mrr: float
    misses: list[str]


def load_questions(path: Path) -> list[Question]:
    questions = []
    for number, line in enumerate(path.read_text(encoding="utf-8").splitlines(), start=1):
        if not line.strip():
            continue
        try:
            raw = json.loads(line)
            questions.append(Question(raw["question"], raw["document"], raw.get("page")))
        except (json.JSONDecodeError, KeyError) as exc:
            raise ValueError(f"{path}:{number}: expected {{question, document, page}}: {exc}") from exc
    return questions


def _document_id(document: str) -> str:
    path = Path(document).expanduser()
    return sha256_of(path) if path.exists() else document


def evaluate(services: Services, questions: list[Question], ks: tuple[int, ...] = (1, 3, 8)) -> Report:
    found = {k: 0 for k in ks}
    reciprocal = 0.0
    misses = []
    for q in questions:
        target = _document_id(q.document)
        hits = search(services, q.question, limit=max(ks))
        rank = next((i for i, h in enumerate(hits, start=1) if h.document_id.startswith(target)
                     and (q.page is None or h.page_start <= q.page <= h.page_end)), None)
        if rank is None:
            misses.append(q.question)
            continue
        reciprocal += 1 / rank
        for k in ks:
            found[k] += rank <= k
    n = len(questions) or 1
    return Report(recall={k: found[k] / n for k in ks}, mrr=reciprocal / n, misses=misses)
```

```markdown
# rag

Hybrid search over a personal PDF library: conference talks downloaded with
[indico-rag](../indico-timetable-tool/indico-rag), papers, theses and notes. Claude Code
queries it through MCP; the same functions are available as the `rag` command.

PDFs are parsed once with [MinerU](https://github.com/opendatalab/MinerU) into text,
tables, equations and figures, split into chunks (one per slide for talks), and stored
in [Qdrant](https://qdrant.tech) with a dense vector (Qwen3-Embedding-0.6B) and a BM25
vector. A search runs both and merges the rankings, so it finds both paraphrases and
exact terms such as isotopes, run numbers and names.

## Setup

Needs Python 3.12, [uv](https://docs.astral.sh/uv/), Docker, and, for figure
descriptions, [Ollama](https://ollama.com) with a vision model.

```bash
uv sync
docker compose up -d                       # Qdrant on localhost:6333
uv run mineru-kit models download --tier standard --source huggingface
uv run rag doctor
claude mcp add --scope user rag -- uv --directory "$PWD" run rag mcp
```

MinerU's models take about 2 GB under `~/.mineru`, the embedding model about 1.2 GB
under `~/.cache/huggingface`, and MinerU's output roughly 1–5 MB per document under
the data directory.

## Use

From Claude Code: "add ~/Desktop/indico-talks/2357_legend-collaboration-meeting-in-naples
as LEGEND talks", then ask questions. Adding runs in the background; ask for the status.

```bash
rag add <path> [--type paper] [--tag legend] [--enrich] [--background]
rag search "Tl-208 background in PPC detectors" [--type talk] [--event 2357] [--since 2025-01-01]
rag status [job-id]
rag enrich <document-id>…        describe figures with the vision model (~30 s per figure)
rag rm <document-id>
rag rebuild                      re-index from cached MinerU output after a model change
rag eval [questions.jsonl]       recall@k and MRR over your own questions
```

A talk is recognised from the `_manifest.json` that indico-rag writes into an event
folder; its title, speakers, session, start time and Indico link come from there.

## Configuration

`~/Library/Application Support/rag/config.toml` (or the file named by `$RAG_CONFIG`).
Keys: `qdrant_url`, `collection`, `dense_model`, `sparse_model`, `device`,
`chunk_tokens`, `mineru_tier`, `ollama_url`, `vision_model`, `data_dir`. An unknown
key is an error.

The collection records the embedding model and chunker it was built with. If the
configuration changes either, every command stops with an error until `rag rebuild`
has re-indexed the library.

## Evaluating retrieval

Write questions you would actually ask to `eval.jsonl` in the data directory, one per
line: `{"question": "...", "document": "<path to the PDF>", "page": 12}` (`page` may
be `null`). `rag eval` reports how often the right page is among the top 1, 3 and 8
results. To compare embedding models, point a second config file at another
collection and model, `RAG_CONFIG=other.toml rag rebuild`, then run `rag eval` with
each.

MinerU is distributed under the MinerU Open Source License (Apache 2.0 with
additional conditions); offering a service built on it to others requires stating
that MinerU is used.

## Facts the code depends on

- MinerU 4's in-process API is `mineru.parse(path, tier=...)`. Its content list is
  rendered from the saved middle JSON via `ParseResult.from_json(...)`; rendering
  from the live result embeds images as base64. Bounding boxes are 0–1000 integers,
  `page_idx` is 0-based. Slide titles carry `text_level`; paper section headings
  often do not.
- MinerU starts PDF render workers with `spawn`; anything that may parse must be
  run under `if __name__ == "__main__":` or the workers die with "PDF render worker
  disconnected".
- The NOW 2026 deck has 30 images on 16 pages, most of them logos; that is why
  `enrich.figures_worth_describing` drops small and repeated images.
- MinerU's table HTML garbles values with super- and subscripts (`61.64+1.8-0.9 kg yr`
  comes out scrambled). The table image is kept in the cache.
- The `mcp` package 2.x has no `FastMCP`; the server class is
  `mcp.server.mcpserver.MCPServer`, and `mcp.Client(server)` tests it in process.
- Files under `~/Desktop` may be iCloud placeholders; reading one downloads it.
